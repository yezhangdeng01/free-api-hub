## 重点新能力

- **免费模型雷达**（`app/freemodels.py`）：定期拉取 OpenRouter 免费模型名单，发现「新面孔」时在模型页顶部弹一次性横幅提醒——判据是「有没有未确认的新东西」而不是「有没有数据」，所以不会反复弹；点确认后才安静。匿名 stealth 模型（名字都藏起来的临测模型）也给档位标注。缓存周期与新面孔认定天数可在设置里调。
- **渠道「额外模型」（`extra_models`）**：免费网关常有「上游 `GET /models` 不列出、但实际能调」的模型。现在渠道表单可以手填这些模型，与上游列表合并展示、参与路由。附带修了一条连带 bug：上游 `/models` 整个挂掉时，只要额外模型非空，渠道不再被整条判停。
- **免费模型自动补全（`modelcat`）**：不想手输模型名的话，渠道表单可勾选「自动补全免费模型」——接 models.dev 公开目录，只取输入/输出都明确标 0 的模型作候选，**探活通过才并入**渠道（撞 429 / 5xx 说明模型存在但忙，转待验证；4xx 直接丢弃），不用再手动一个个添。
- **统计页每日请求量：单柱拆双柱**。同一天 = 左柱请求次数（沿用成功/中断/失败三层配色）+ 右柱 Tokens 消耗（青绿单色，只表体量）。两组各按自己的区间峰值归一化并留 15% 余量；请求柱逐日封顶、恒低于 Tokens 柱（量级差 3~4 个数量级，等高对比没有意义）；柱顶数字按柱色着色、贴各自柱顶，放不下时自动避让（矮柱数字不高过高柱）；Tokens 数字统一「万」单位带小数（柱顶 / 悬停 / 图例 / 总量卡四处同口径）。

## 判定与稳定性

- **429 误判修复 + 探活收紧**：免费模型撞 429 不再被兜底判成「账户余额不足，需充值」；分钟级限流（上游瞬时抖动）与「额度用尽」分离记账，限流黄标等待恢复而非标红 down、重启不回；「余额 ≤ 0」的兜底分支不再误伤免费模型。探活判据从「`/models` 里存不存在」收紧为「实际能不能调通」。
- **渠道级地域封锁穿透**：Google Gemini 这类按出口 IP 封锁的渠道，旧行为是一句「渠道无效、已停用或未提供该模型」满屏糊脸，还可能连坐整条渠道。现在按响应**正文措辞**识别地域封锁（不是看 HTTP 状态码）：只标「受限」，不写稳定分、不标 down；「扫描全部模型」能真实逐模型推进，换到支持地区的出口后，下一轮健康检查自动回绿（默认 30 分钟）。

## 已知限制

- 被地域封锁的渠道，在换到支持地区的出口之前，健康检查显示全模型「受限」黄标——**这是预期行为**，不是故障；换出口后自动恢复。
- 自动补全依赖 models.dev 公开目录的快照（有缓存周期），刚上线几天的模型可能滞后一轮才被补进。
