# v1.0.6 发布说明

> 自 v1.0.5 起的累积更新，共 23 项改动（15 个文件、5050 行）。全量测试 **161 passed**，零回归。

## 重点新能力

- **`/v1/responses` 翻译层**：OpenAI Responses 协议（Codex CLI / 新版 SDK 只认这个端点）↔ `/v1/chat/completions` 双向翻译。请求译完交给 `_chat_v1`，复用全部路由 / 冷却 / 会话粘性 / 记账；流式旁路转 SSE，覆盖 reasoning / 文本 / 工具调用增量、`custom_tool_call` 还原、`[DONE]` 不外泄。已用双 uvicorn 真 TCP 流式验过 15 种事件名与 `call_id` 闭合，生产侧 vibe-astock「接入 AI」probe 通过。
- **namespace 工具摊平**：codex 0.153 把 MCP 工具打包成 `{type:"namespace", tools:[…]}`，旧翻译层当未知类型丢弃 → 模型看不到工具。现已摊平进 chat tools，并在回包 `function_call` 补回 `namespace` 字段（codex 靠它路由 MCP，非流式 / 流式两处都补）。
- **`auto-*` 连字符别名**：`auto-balanced / -quality / -speed / -stability / -vision`。部分客户端（如 codex）把模型名限死在 `[A-Za-z0-9._/-]`，冒号会注入 config TOML 被禁。冒号版 `auto:*` 已删除（再填会当普通模型名查 → 404）。

## 稳定性与判定

- **榜单缓存落盘**：AA 榜分 / 视觉能力不再依赖 OpenRouter 在线；公开端点免密钥兜底；空态拒写盘；兜底与渠道检查并行。启动耗时 4.0s → 1.1s。
- **睡眠唤醒自愈**：整轮全挂且全是本机网络错误 → 10s~60s 短退避重试（原来要等一整个检查周期）；唤醒检测 + 重建连接池；降级期不写模型状态、不烧探测额度。
- **记账口径修正**：流式「同一 chunk 先解析再转发」→ 客户端收到结束标记就断连不再被记成中断；新增 `usage.superseded`（失败但已换路）；客户端中断时看模型有无输出 → 有输出记成功（标「客户端中断」），一个字没出才记「已中断」。
- **中断行 Tokens 列**：新增 `usage.out_chars`（实际输出字符数）+ 老行回填，照实显示「17,374 字」而非「—」。
- **OpenRouter 免费模型余额误判修复**：`free_daily` / `minute` 的正文分类不再被余额接口覆盖。
- **启动归正判据收窄**：每日额度冷却文案不再被误升成永久 down。
- **`down` 的出口（方案 B）**：手动测试成为 `down` 唯一出口；前端补「● 不可用 N」开关（默认关）+ 红点行 + 行内「测试」键。
- **模型级状态退出可用性判定（A1）**：改为纯展示，可用性只看渠道聚合；新增 `channels[].unavail_reason` / `models[].test_channel`；渠道 chip 红=不可用、原因全进悬停。
- **手动测试候选口径对齐**：活渠道优先、所有渠道试完才定论；返回值加 `attempts`（逐条列出试过哪几条渠道）。

## 体验与界面

- **排序视图修复**：`compScore` 改读当前视图，四个 chip 顺序各不相同。
- **前端 `no-store`**：`/` 加 `Cache-Control: no-store`，托盘加「刷新界面」——改前端不必再重启。
- **手动档位**：模型页点档位 chip 改档，落 `model_tier_exact`（点名表，优先于正则表）。
- **视觉专属收藏**：`pinned_vision` 独立于主收藏，只管视觉视图与 `auto-vision`。
- **会话粘性**：`auto-*` 认会话（首条 user 消息指纹 / 显式头），粘住本会话上次成功产出的模型，只有它失败才换；落 `runtime_state.json` 重启不丢；新增 `GET/DELETE /api/sticky`。
- **官方额度响应头**：接上魔搭 `modelscope-ratelimit-*` 4 个头（模型级 → `ratelimit`，账号级 → `user_quota`），额度见底提前换路；429 降级到模型级（≥4 个不同模型短窗口爆发才判账号级）。
- **速度维 log 线性化**：`400/(400+ms)` 改为 `log` 线性化，速度优先视图桶内排序真正生效（前后端同步）。
- **工具条布局修复**：整页 `max-width` 1180 → 1300，工具条 `flex-wrap` + 分组，杜绝组内折行。
